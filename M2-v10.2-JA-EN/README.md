## 音と操作

基準のC4は440×2^(−9/12) ≈ 261.625565Hzです。通常の音は正弦波、三角波の参照音のみ奇数倍音を1/n²の振幅で合成しています。

- 右上の音量アイコンを押すと音量調節が開きます。その横の波形は実際の音声出力です。
- ページを一度クリックした後、比にマウスをかざすと発音します。タッチやキーボードではボタンを押してください。本文の整数・分数比は、1をC4として値のまま鳴らします。表内の比は各表の基準音に従います。
- 表の一斉再生は3秒間。表内の単音とともに160msのアタックで立ち上がります。再生ボタンをもう一度押すと停止します。
- 最初の円環はドラッグでC4のオクターブ内を演奏できます。再生ボタンではC3からC7へ上昇し、各Cを保持した後、5つのCを同時に鳴らして繰り返します。
- 倍音を重ねる2種類の再生はC3から開始します。根音と奇数音名の演奏は1（ユニゾン）、3、5…を追います。
- C/G演奏欄はクリックで持続ON/OFF。枠内にフォーカスがある間、数字キーでも演奏できます。クリックで保持した音と数字キーは共存します。低いC/Gも独立して持続できます。
- 別の試聴を始めると前の再生を止めます。ページを非表示にしても停止します。
